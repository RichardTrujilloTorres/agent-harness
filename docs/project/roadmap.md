# Roadmap

You will be able to tell what agent-harness does today from what is only planned.

::: warning Not built
Everything on this page is an idea under consideration. None of it exists in the code, and there is no date or commitment for any item.
:::

## Planned ideas

| Idea | What it would add |
| --- | --- |
| Voice mode | Text-to-speech for the user, speech-to-text for the agent, and barge-in, to test voice agents |
| More adapters | Transports other than HTTP with JSON |
| Parallel runs | Running several scenarios at the same time |

## What exists today

Text conversations with an agent over HTTP, scripted or LLM-played users, deterministic expectations and an LLM judge, retries with FLAKY detection, text, JSON, HTML, JUnit and transcript output, a Pest plugin and a PHAR build. The [Reference](../reference/cli.md) lists exactly what the tool accepts.

To discuss an idea, open an issue in the repository before writing code, as [Contributing](contributing.md) asks.
